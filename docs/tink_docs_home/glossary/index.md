## Tink Glossary

Read the Glossary to learn more about Tink products and services and other concepts that might need further explanation.

## Client token

The Tink API can be accessed with different API tokens. The client token is used to authenticate and authorize you to access your app. Read more about access tokens in our [guide](/Tiny-doc/tink_docs_home/resources/getting-started/get-access-token/).

## Permanent users

A _Tink User_ is an internal reference that links together aggregated financial data belonging to the same person or entity, such as consents, accounts and transactions. By default, all Tink users and their corresponding data are automatically deleted after 24 hours. When [Continuous Access](/Tiny-doc/tink_docs_home/resources/transactions/continuous-connect-to-a-bank-account/) is enabled, your users will not be automatically deleted, enabling you to continuously access and refresh data. Contact us to get this feature enabled.

## Tink Link

Tink Link is our front-end SDK for end-user authentication. Using Tink Link, you have access to a ready-made authentication flow with a single line of code - regardless of bank or market. To get started, check out our [getting started guide for Tink Link](/Tiny-doc/tink_docs_home/resources/getting-started/connect-tink-link/).

## Tink Link iframe

The [Tink Link](#tink-link) SDK can be integrated inside an `<iframe>` element. For security reasons, this feature is blocked by default. To request the ability to embed Tink Link, go to **Console** > \[**your\_app**\] > **App settings** > **App details** > **Display name (public)** and select **Verify**. If you’re curious to know more, read our [web](/Tiny-doc/tink_docs_home/resources/tutorials/iframe/) and [iOS](/Tiny-doc/tink_docs_home/resources/tutorials/iframe-for-ios/) tutorials.

## User token

The Tink API can be accessed with different API tokens. The user token is used to authenticate and authorize access of a single user connected to your app. Read more about access tokens in our [guide](/Tiny-doc/tink_docs_home/resources/getting-started/get-access-token/).
