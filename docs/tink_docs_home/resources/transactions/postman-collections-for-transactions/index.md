This article shows how to use Tink's Postman collections for Transactions. For documentation and help to use Postman, go to the [Postman docs introduction](https://learning.postman.com/docs/getting-started/introduction/)

**Note**: Postman is a third-party company that makes an API platform for building and using APIs. To use the Postman collection for Transactions, you must first either [sign up for a Postman user account](https://www.postman.com/) to use Postman or download and install their app.

## How to use the Postman collections[](#how-to-use-the-postman-collections)

Step-by-step instructions on how to use our Postman collections for Transactions are found in Postman. To see the instructions:

1.  Open a Postman collection.
2.  Select the documentation icon in the context bar (which is found on the right-hand side of the Postman screen).

For help on how to view documentation in Postman, see [Viewing documentation for a collection](https://learning.postman.com/docs/publishing-your-api/viewing-documentation/).

## Postman collections list[](#postman-collections-list)

There are currently three Postman collections available for Transactions:

-   [One-time access](#one-time-access): one-time retrieval of transaction data.
-   [Continuous access](#continuous-access): uninterrupted access to transaction data.
-   [Account Check and Transactions with continuous access](#account-check-and-transactions-with-continuous-access): allows two Tink products to work together.

### One-time access[](#one-time-access)

To download this Postman collection, follow these steps.

1.  Open the [tink-postman](https://github.com/tink-ab/tink-postman) GitHub repo.
2.  Select **Code** > **Download ZIP**.
    
    A ZIP file is downloaded to your computer.
    
3.  Open the ZIP file and extract the file named `Transactions one-time access.postman_collection.json` to your computer.

#### Import the collection[](#import-the-collection)

To import the Postman collection by using the Postman app that is installed on your computer, follow these steps.

1.  Open Postman.
2.  Select **File** > **Import** > **Upload files**.
3.  Open the Transactions JSON file that you have downloaded and extracted.
4.  Select **Import**.

The Postman collection for one-time access is now imported to Postman.

For step-by-step instructions from this point, see [How to use the Postman collections](#how-to-use-the-postman-collections).
