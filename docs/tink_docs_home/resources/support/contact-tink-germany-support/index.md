Support for Tink products is managed in the Visa Support Hub. There, you can create, view, and manage cases together with Tink Support to get the help you need.

> **Note**: This article outlines how to contact Tink Germany Support for customers who use XS2A. **If aren't operating in Germany or don't use X2SA**, see [Contact Tink Support](https://docs.tink.com/resources/support/how-to-find-technical-support).

## How to access Visa Support Hub[](#how-to-access-visa-support-hub)

To access the Visa Support Hub (VSH), you'll need a Visa Support Hub account. If you don't have an account, [contact Sales](https://tink.com/contact-us/).

When you have an account, visit the [Visa Support Hub sign-in page](https://visasupporthub.visaonline.com/). Then, select **Sign in - Tink Germany (XS2A)**, and then **Password**.

![Visa Support Hub Login Germany](https://images.ctfassets.net/tmqu5vj33f7w/6tDOUKrUTIFYvP3qwxnM0J/2457a186b03b4b26544a045090aed668/VSH-Login-Germany.png)

After signing in, you'll redirected to the Visa Support Hub homepage.

## Create a case[](#create-a-case)

To create a case, visit the Visa Support Hub and select a support topic.

![VSH Create Case Germany](https://images.ctfassets.net/tmqu5vj33f7w/hDQ0NqJ2Y0x9lo75o4JKJ/c247026b612a89872fbc29855d454af3/Create-Case-Germany.png)

After selecting the topic, fill out the case form.

![VSH Germany Case Form](https://images.ctfassets.net/tmqu5vj33f7w/4fOAx7d8YmUEDnK8z2SAg2/5f4473297ebe242f5f8d6b8fb4c6d6b4/VSH-Germany-Case-Form.png)

![VSH Germany Create Case From Header](https://images.ctfassets.net/tmqu5vj33f7w/6VjjosUfMcaKEdLwcGYQoS/1af1be77f065296f4142c3ebae747cfb/VSH-Germany-Create-Case-From-Header.png)

### Reporting a defect[](#reporting-a-defect)

To resolve your case as quickly as possible, we'll need some information from you. For example:

-   What percentage of your users are affected, and how?
-   Which Tink products are affected? Does the issue relate to a specific API endpoint and/or integration provider?
-   What is the [userId](https://docs.tink.com/api#general/user), [credentialsId](https://docs.tink.com/api#connectivity/credentials) or [payments request id](https://docs.tink.com/api#payment/payment-request) related to the issue
-   For Tink Link users: what is the full response from Tink Link (with any sensitive info redacted)
-   When did the issue occur?
-   What's your application’s `clientId`?

> If information is missing and the defect is urgent, don't worry. Just report the defect and we'll work together to find out what we need to know.

## Manage cases[](#manage-cases)

You can manage your cases from the case dashboard.

![VSH Germany Case Dashboard](https://images.ctfassets.net/tmqu5vj33f7w/4vLO4Hd61QBg9ZnRPHE1c4/ee2768fdfeb411e5f4f0bb700834012c/VSH-Germany-Case-Dashboard.png)

Each case has a status, which gives you a good sense of how a case is progressing or what actions are needed from you at a glance.

**Case Status Definitions**

| Case Status | Description |
| --- | --- |
| Pending Visa | Automatically assigned when a new case is created. Indicates that we're actively working on your case |
| Pending Client | We've requested information or feedback from you |
| Pending Closure | Set by Customer Support when the case appears to be resolved. You have up to 5 days to add input before the case closes automatically |
| Close | The case is resolved and officially closed. If needed, you can reopen it within 5 days of closure |
| Cancellation Requested | You've submitted a request to cancel the case |
| Cancelled | The case has been officially cancelled and is no longer active |

You can view and update a case by selecting it from the case dashboard. Here, you can view the case activity and add details about the case.

![VSH Case Management Germany](https://images.ctfassets.net/tmqu5vj33f7w/2dlsqblRXV2l2jL6fqLrry/4a037c9dc787e02ab87247a55db49c7d/VSH-Case-Management-Germany.png)
