## Create an organisation[](#create-an-organisation)

When you first sign up you enter an **Organisation name**, and after successfully registering you have created your first user account for in a new organisation. Any user with the Administrator role can later change that name in the Organisations tab (being the first user in an organisation you are automatically assigned the Administrator role). *Image removed: external*

## Inviting and removing team members[](#inviting-and-removing-team-members)

In the Organisations tab, you can invite more users to join your organisation. For each invite you’ll select a role and email address. The invited person will receive an invite email to create an account. Once accepted, this user will now be a part of your organisation. In the same section you (as Administrator) can remove team members or change their role. *Image removed: external*

## Changing organisation[](#changing-organisation)

If you have created an account before being invited to an organisation, you do not need to create a new account, you will just have to accept the invite to join the new organisation. This means that you will now be a member of two organisations. When logged in, you can easily switch which organisation you are viewing by selecting it in the bottom left menu - where you also find the logout button. *Image removed: external*

## Security[](#security)

For increased security each user can activate two-factor authentication their account. We support both common authentication apps and recovery codes. You find these settings under the Security section. In the organisation tab you can view which users have activated the two-factor authentication. *Image removed: external*

## FAQ[](#faq)

**Can I be a part of multiple organisations?**

-   Yes you can! Once you accept an invite you’ll be part of that organisation.

**Can you change the role of a user?**

-   Administrator users can change the role of other users in the organisation.

**Can I remove an organisation or my user account?**

-   Yes, contact support.

**Can I remove a user with the administrator role?**

-   Yes, administrator users can remove any user in the organisation - regardless of their role.

**Is there a limit on number of members in an organisation?**

-   No limitation (at the time of writing)

**Will I be logged out automatically?**

-   Yes, a session is valid for 3 hours.

**How long does an invite last?**

-   An invite is expired after 15 days.
