## Create an organisation[](#create-an-organisation)

When you first [sign up](https://console.tink.com/signup) you enter an **Organisation name**, and after successfully registering you have created your first user account for in a new organisation. Any user with the Administrator role can later change that name in the [Organisations tab](https://console.tink.com/account/organization/users) (being the first user in an organisation you are automatically assigned the Administrator role). ![](https://images.ctfassets.net/tmqu5vj33f7w/4GJlsRgRcJjGXrJ7xgN0ts/0ea7c24f48962b4f5e8a1bdb161f48b7/Screenshot_2020-10-23_at_13.23.50.png)

## Inviting and removing team members[](#inviting-and-removing-team-members)

In the Organisations tab, you can invite more users to join your organisation. For each invite you’ll select a role and email address. The invited person will receive an invite email to create an account. Once accepted, this user will now be a part of your organisation. In the same section you (as Administrator) can remove team members or change their role. ![](https://images.ctfassets.net/tmqu5vj33f7w/PRsEp303fuORbxVloQeDl/317a612c6ce2e67530ac07542998bad1/Screenshot_2020-10-28_at_12.28.19.png)

## Changing organisation[](#changing-organisation)

If you have created an account before being invited to an organisation, you do not need to create a new account, you will just have to accept the invite to join the new organisation. This means that you will now be a member of two organisations. When logged in, you can easily switch which organisation you are viewing by selecting it in the bottom left menu - where you also find the logout button. ![](https://images.ctfassets.net/tmqu5vj33f7w/7Cl3FIPpYkg8p541lcVexW/5e8756b757d6fceb200cc56b4b06c092/Screenshot_2020-10-23_at_13.37.46.png)

## Security[](#security)

For increased security each user can activate two-factor authentication their account. We support both common authentication apps and recovery codes. You find these settings under the [Security section](https://console.tink.com/account/profile). In the organisation tab you can view which users have activated the two-factor authentication. ![](https://images.ctfassets.net/tmqu5vj33f7w/30jVDOlBxsOMsn3lC9kkyx/d31f4fa557367348cc3ddff4b58966e4/Screenshot_2020-10-23_at_13.40.21.png)

## FAQ[](#faq)

**Can I be a part of multiple organisations?**

-   Yes you can! Once you accept an invite you’ll be part of that organisation.

**Can you change the role of a user?**

-   Administrator users can change the role of other users in the organisation.

**Can I remove an organisation or my user account?**

-   Yes, contact support.

**Can I remove a user with the administrator role?**

-   Yes, administrator users can remove any user in the organisation - regardless of their role.

**Is there a limit on number of members in an organisation?**

-   No limitation (at the time of writing)

**Will I be logged out automatically?**

-   Yes, a session is valid for 3 hours.

**How long does an invite last?**

-   An invite is expired after 15 days.
