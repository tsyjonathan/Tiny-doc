This article shows how to use Tink's Postman collection for Expense Check. For documentation and help to use Postman, go to the [Postman docs introduction](https://learning.postman.com/docs/getting-started/introduction/)

**Note**: Postman is a third-party company that makes an API platform for building and using APIs. To use the Postman collection for Expense Check, you must first either [sign up for a Postman user account](https://www.postman.com/) to use Postman or download and install their app.

## Download the Postman collection[](#download-the-postman-collection)

To download our Postman collection, follow these steps.

1.  Open the [tink-postman](https://github.com/tink-ab/tink-postman) GitHub repo.
2.  Select **Code** > **Download ZIP**.
    
    A ZIP file is downloaded to your computer.
    
3.  Open the ZIP file and extract the file named `Expense Check.postman_collection.json` to your computer.

## Import the Postman collection[](#import-the-postman-collection)

### Online[](#online)

To import the Postman collection online, follow these steps.

1.  Go to Postman and sign in.
2.  Select **Import file** > **Upload files**.
3.  Open the Expense Check JSON file that you have downloaded and extracted.
4.  Select **Import**.

The Postman collection for Expense Check is now imported to Postman.

### Postman app[](#postman-app)

To import the Postman collection by using the Postman app that is installed on your computer, follow these steps.

1.  Open Postman.
2.  Select **File** > **Import** > **Upload files**.
3.  Open the Expense Check JSON file that you have downloaded and extracted.
4.  Select **Import**.

The Postman collection for Expense Check is now imported to Postman.

## Documentation[](#documentation)

The Postman collection for Expense Check contains documentation. The documentation contains prerequisites to get your API credentials, and a guide that shows you how to fetch data via our API to get an Expense Check report as a JSON or PDF file.

To view the documentation in the Postman collection, follow these steps.

1.  Open the Postman app or sign in to Postman (online).
2.  Select **Collections** in the left-hand sidebar.
3.  Select **Documentation** in the right-hand context bar.

For more information on how to see documentation in Postman, see [Viewing documentation](https://learning.postman.com/docs/publishing-your-api/viewing-documentation/).
